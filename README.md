# Credit Risk Analysis Dashboard
## SQL · Power BI

## Project Overview
Analyzed a 50,000-row loan dataset to identify high-risk borrower 
segments and build an interactive credit risk dashboard.

## Key Finding
Borrowers with credit utilisation >75% show a 3x higher default 
rate compared to low-utilisation borrowers.

## SQL Techniques Used
- CTEs (Common Table Expressions)
- Window Functions (rolling averages, running totals)
- Joins
- Aggregations and CASE statements
- Risk segmentation logic

## Dashboard KPIs
- Total Loans: 50,000
- Overall Default Rate: 20.99%
- Total Loan Volume: 841M
- Average FICO Score: 714

## Visualisations
- Default rate by loan grade (A–G)
- Default rate by credit utilisation bucket
- Monthly default rate trend with rolling average
- Loan distribution by risk segment (donut chart)

SQL (SQLite) · Python · Power BI Desktop
